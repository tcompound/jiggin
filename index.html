What it does

Reputation that survives the server, not just the chat log

Every vouch is written to a persistent ledger the moment it's given — separate from the channel it was posted in. That's what makes restoring it possible.

One-command restore

Run /restore @user in any server and their full vouch history reappears — same count, same timestamps.

Off-channel ledger

Vouches live in a synced ledger, not just chat history — so deleting the channel doesn't touch the record.

Fraud safeguards

Cooldowns, duplicate detection, and a full audit trail keep the ledger honest as it grows.

Server leaderboard

A live ranking of your most-vouched members, restored right alongside everyone's counts.

Custom vouch format

Require proof, amount, or method on every vouch — configured per server, restored the same way.

Full control panel

Set the vouch channel, cooldown, and required roles from a dashboard built for admins, not spreadsheets.

How restoring works

Three steps, from first vouch to full recovery

This is the actual sequence — the ledger has to exist before there's anything to restore.

1

Every vouch gets logged

The moment a member is vouched for, it's written to the persistent ledger — not just left sitting in chat history.

2

The server changes

A nuke, a raid, a channel purge, or a full recreation — the messages are gone, but the ledger entry isn't.

3

Run the restore command

Any admin runs /restore on the member — and their full vouch count reappears intact.

Stop starting reputation from zero

Add VouchRestore to your server and the ledger starts building immediately.
